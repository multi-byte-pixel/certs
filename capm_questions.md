# CAPM Practice Questions (Q1-Q35 captured so far)

Source: "This video will make you pass the CAPM exam - 150 Questions" (YouTube)

1. Mid execution a sponsor requests the project manager to terminate the project. What should the project manager do?
2. Which technique involves prioritizing features, epics, or user stories by business value in a sequential manner?
3. In which scenario would you use a use case diagram over a story map?
4. A project manager is leading a project that has expanded significantly. As a result, the sponsor has been replaced by a steering committee. What should the project manager do to adapt to this change?
5. A project manager has made certain that all of the required tasks have been accomplished. However, upon an external post-completion audit, a significant penalty was imposed on the performing organization. What could the project manager have done differently to make sure that no liabilities arose following the audit?
6. An organization is launching a project to create an innovative product. The details of the components of work packages have been defined and constraints for each component have been identified. Top management requested a precise cost estimate of the project. What estimate technique should the project manager use?
7. A project manager is facing a market opportunity. How should the project manager categorize an opportunity?
8. After facing multiple quality issues, the project manager decided to identify top priority defects by applying the 80/20 rule (Pareto chart). What should the project manager do next?
9. A project manager is assessing the project's financial status by calculating the difference between the earned value and actual cost. What is the project manager calculating?
10. What is the primary purpose of project governance?
11. After purchasing new software needed for the project, a project manager identifies a potential risk: the version might be old. The project manager decides to passively accept the risk. Why is passive risk acceptance the appropriate approach?
12. A project manager is leading a predictive project. After identifying a risk, the project manager decides to transfer it to another party. What is the option to transfer it?
13. A solar-powered car project is almost finished when the project manager receives an approved change request to replace a defective component of the car batteries. What should the project manager do?
14. What is the best type of communication to inform a subcontractor of the contract discontinuation decision?
15. A project manager is facing a complicated quality problem that they don't understand the source and causes of. What tool or technique should they use to trace the problem source back to its root cause?
16. An organization in need of accounting software conducts a make-or-buy analysis and decides to go for in-house development. However, when acquiring resources, the project manager finds out that the developer rate included in the analysis is only half the current market rate. What should the project manager do first?
17. A team member developed a new feature that caused regressions on other features already used by the client. What should the project manager do?
18. An organization recently transitioned to the agile approach. However, project team members always wait for the project manager to assign them work. How can the project manager help the team become self-organized?
19. A project manager is assigned to lead a large project with a cost variance of -$40,000, an actual cost of $200,000, and a planned value of $140,000. Based on these numbers, how much is the project's earned value?
20. The project manager resorts to management reserve to handle which type of risk: known-unknowns, known-knowns, business risks, or pure risks?
21. Which of the following is considered an organizational process asset: organizational culture, market standards, corporate knowledge base, or project management information system?
22. From past experience, the project manager of a construction project knows there is a risk of not receiving the needed sand supply on time. If this risk occurs, the project manager would purchase sand from another supplier. What is this risk response? Also, if there's a resulting difference in sand quality, what is that new risk called?
23. Which of the following is an example of an appraisal cost in the context of quality management: testing services, training and mentoring, complaint handling, or troubleshooting errors and defects?
24. Which of the following refers to the start-to-finish time required to develop a potentially shippable product increment?
25. Upon reviewing user stories, the agile coach finds that some do not follow the common template format. Which format should the agile coach instruct the development team to follow for user stories?
26. During the solution evaluation phase, a business analyst realizes that the implemented solution is underperforming and not meeting the expected business value. What actions should the business analyst take to assess and address the issue? (Select two)
27. The following chart was presented during a retrospective meeting. Which of the following statements is true regarding this chart (burndown chart)?
28. A project manager is facing some challenges because of a key stakeholder. The project manager collaborated with this stakeholder in previous projects where the latter frequently changed requirements and created trouble whenever those requirements were not met. How should the project manager deal with this issue?
29. A project manager is assigned to lead a project abroad. At the start of project execution, the project manager gets worried about the country's high levels of violence in public. The project manager gets approached by a local police officer who pledges to keep the project team safe during their stay in return for a private money transfer. How should the project manager respond?
30. During a meeting, a team member asks the project manager if there is really a difference between precision and accuracy. How should the project manager reply?
